# Villa roof play — 3D

Interactive Three.js model of a Bali villa with a kids' play roof.

- `v2/` — jacuzzi under a thatched roof, bamboo lookout tower, woven crawl tube, slide into the pool, trampoline. Click a character (or its head icon, top-left) to drive it: arrows walk/turn, Shift runs, Space jumps, Esc or click elsewhere to let go.
- `v1/` — earlier timber play-deck version.
- `line.html` — first lines-only sketch.

All dimensions are estimates from photos. No build step; open over http.
